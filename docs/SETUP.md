# あいぼう手帳 セットアップ手順（購入者向け）

自分専用のライフログアプリを、自分のNotionにつないで動かすまでの手順です。

> Notionを使っていない人（家族・友人など）にも使ってもらいたい場合は、
> メールアドレスだけでログインできる **Web版** の手順（`docs/SETUP-web.md`）を見てください。
> この手順書は「記録を自分のNotionに残したい人」向けです。
**かかる時間はだいたい15分**、月々の費用は基本的に**0円**です
（AI機能を使う場合だけ、OpenAIの利用料が数十円〜数百円かかります）。

プログラミングの知識は要りません。上から順にそのままやれば動きます。

---

## 用意するもの

| 必要なもの | 費用 | 何に使うか |
|---|---|---|
| Notionアカウント | 無料 | 記録の保存先 |
| GitHubアカウント | 無料 | アプリのコードを置く場所 |
| Renderアカウント | 無料 | アプリを動かすサーバー |
| OpenAI APIキー | 従量課金（任意） | 音声入力・カロリー推定・ふりかえり |

OpenAIキーは**無くても動きます**。その場合、音声で記録・カロリーの自動推定・
毎日のふりかえりコメントの3つが使えないだけで、記録そのものは問題なくできます。
あとから足すこともできます。

---

## 1. Notionにテンプレートを複製する（2分）

1. 購入時に届いたNotionテンプレートのリンクを開く
2. 右上の**「複製」**を押して、自分のNotionに取り込む
3. 取り込んだページを開いたまま、次へ進む

## 2. Notionの鍵（トークン）を作る（3分）

1. https://www.notion.so/my-integrations を開く
2. **「新しいインテグレーション」**を作成する
   - 名前は `aibou-techo` など分かるものでOK
   - 関連ワークスペースは、テンプレートを複製したワークスペースを選ぶ
3. 作成後に表示される**「内部インテグレーションシークレット」**をコピーしておく
   （`ntn_` または `secret_` で始まる長い文字列）

> このトークンは、あなたのNotionを操作できる鍵です。人に見せないでください。

## 3. テンプレートにトークンを接続する（1分）

1. 手順1で複製したNotionページを開く
2. 右上の**「…」→「接続」**（コネクトの追加）から、手順2で作ったインテグレーションを選ぶ
3. ページのURLをコピーしておく

URLは次のような形です。末尾の32文字が**ページID**です。

```
https://www.notion.so/ライフログ-1a2b3c4d5e6f7890abcdef1234567890
                                  ↑ この32文字がページID
```

## 4. コードを自分のGitHubに置く（3分）

1. 購入時に届いたZIPファイルを解凍する
2. https://github.com/new で新しいリポジトリを作る（**Private**でOK）
3. 解凍した中身をそのリポジトリにアップロードする
   - GitHubの画面から「uploading an existing file」でドラッグ＆ドロップできます
   - `node_modules` フォルダは**含めないでください**（無くても動きます）

## 5. Renderにデプロイする（4分）

1. https://render.com にGitHubアカウントでサインアップする
2. **New → Web Service** を選び、手順4のリポジトリを指定する
3. 設定は次のとおり（ほとんど自動で入ります）

   | 項目 | 値 |
   |---|---|
   | Environment | Node |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | Free |

4. **Environment Variables** に、AI機能を使う場合だけ次を追加する

   | キー | 値 |
   |---|---|
   | `OPENAI_API_KEY` | 自分のOpenAI APIキー |

   > `NOTION_TOKEN` と `NOTION_PAGE_ID` は**設定しないでください**。
   > アプリの設定画面から入れる方式のほうが安全で、あとから変更もできます。

5. **Create Web Service** を押して、デプロイが終わるのを待つ（3分ほど）
6. 完了すると `https://〇〇.onrender.com` のURLが発行される

## 6. アプリにNotionをつなぐ（2分）

1. 発行されたURLをスマホのブラウザで開く
2. 初回は自動で「Notion連携の設定」画面が開く（開かなければ右上の⚙️から）
3. 手順2の**トークン**と、手順3の**ページID**を貼り付けて保存する
4. 何か1件記録してみて、Notionのページに追記されれば完了です

## 7. スマホのホーム画面に追加する（1分）

- **iPhone**：Safariで開き、共有ボタン → 「ホーム画面に追加」
- **Android**：Chromeで開き、メニュー → 「ホーム画面に追加」

アプリのように全画面で開き、オフラインでも最後に見た記録が表示されます。

## 費用について

- **Notion / GitHub / Render**：この使い方なら無料枠に収まります
- **OpenAI**：使った分だけの従量課金です。音声入力とカロリー推定を毎日使っても、
  月にコーヒー1杯ぶんに届くかどうかという規模ですが、**正確な料金はOpenAIの
  管理画面で必ず確認してください**。使いすぎが不安な場合は、OpenAI側で
  月額の上限（Usage limits）を設定しておくと安心です

## Render無料プランについて

無料プランは、しばらくアクセスがないとサーバーが眠ります。次に開いた時に
起き上がるまで30秒ほどかかることがあります（この間に記録しても、端末に
いったん保存されて自動で送り直されるので、記録が消えることはありません）。

待ち時間が気になる場合は、Renderの有料プランに切り替えると常時起動になります。

## うまくいかない時

**「Notionに書き込めません」と出る**
→ 手順3の「接続」ができていない可能性が高いです。Notionページの「…」→「接続」に、
作ったインテグレーションが並んでいるか確認してください。

**ページIDが分からない**
→ NotionページのURLの、最後の `?` より前にある32文字です。ハイフンが入っていても
そのまま貼り付けて大丈夫です。

**音声ボタンを押しても反応しない**
→ `OPENAI_API_KEY` が設定されていないか、ブラウザのマイク許可が下りていません。
Renderの環境変数と、端末のマイク許可の両方を確認してください。

**デプロイが失敗する**
→ `node_modules` フォルダごとアップロードしていないか確認してください。
容量が大きすぎて失敗することがあります。

## 大事なお知らせ

- カロリーの数値と、キャラクターからのコメントは**あくまで目安**です。
  医学的・栄養学的な助言ではありません。健康上の判断は医師や専門家にご相談ください
- 記録はあなた自身のNotionに保存されます。作者のサーバーには保存されません
- Notionトークンは、あなたの端末のブラウザにだけ保存されます
