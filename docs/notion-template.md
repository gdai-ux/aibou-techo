# 販売用Notionテンプレートの作り方

Gumroadで配る「複製リンク」用のNotionページを、自分のNotionに1回だけ作る手順。
アプリが書き込む形に合わせてあるので、この通りに作れば買った人がそのまま使える。

## 作成済みのページ

下記の構成のページは、Notionのプライベートページとして作成済み。

- **🌱 ライフログ** — https://app.notion.com/p/3ce5a555c4ea8104a894f1d1f450d283

中身は以下のとおり。

- 冒頭のコールアウト（このページに記録がたまる、という案内）
- トグル「はじめにお読みください」（免責を含む）
- トグル「セットアップ手順（15分）」（`docs/SETUP.md` と同じ内容）
- トグル「うまくいかない時」
- トグル「記録はこんな形でたまります（サンプル）」
- トグル「使い方のヒント」
- 区切り線と「ここから下に記録が追記されます」の案内

### 残っている作業（Notionの画面でしかできない）

APIからは公開設定を切り替えられないので、次の2つは手で行う。

1. カバー画像とアイコンの見直し（アイコンは🌱を設定済み）
2. **共有 → Webで公開 → 「テンプレートとして複製を許可」をオン**にして、
   URLの末尾に `?duplicate=true` を付けたものを複製リンクとして使う

## 大前提：アプリが書き込む形

アプリはNotionページに、この形で追記していく。

```
## 2026-09-01（火）        ← 日付の見出し（H2）
睡眠：23:15就寝、06:20起床（7時間5分）
運動：08:35 ショルダープレス20キロ×3
朝食
・白米（約240kcal）
・味噌汁
体調：07:05 良い（排便：普通）
メモ：09:30 今日もやるぞ
振り返り：おお、今日もいい感じで進んでるな！
```

**つまりテンプレート側は「空のページ」でよい。** 中身はアプリが作る。
テンプレートの価値は、記録そのものではなく**その周りの見せ方と説明**にある。

## テンプレートの構成（推奨）

1ページで完結させる。複雑にするほどサポートが増える。

### ① 表紙とタイトル

- タイトル：`🌱 ライフログ`
- カバー画像とアイコンを設定する（見た目の印象がそのまま商品の印象になる）

### ② はじめにお読みください（トグルで閉じておく）

中身はセットアップ手順（`docs/SETUP.md`）へのリンクと、次の3行。

- 記録はこのページの下に、日付ごとに自動で追記されます
- このページを消したり、名前を変えたりしても大丈夫です（IDが変わらなければ動きます）
- カロリーやコメントは目安です。医学的な助言ではありません

### ③ セットアップ手順（トグル）

`docs/SETUP.md` の内容をそのまま貼る。買った人はNotionしか見ない可能性が高いので、
**PDFやGumroadの説明文だけに置かず、テンプレートの中にも必ず入れる。**

### ④ 記録が入る場所

見出しだけ置いて、下は空にしておく。

```
---
（ここから下に、アプリが日付ごとの記録を追記します）
```

サンプルとして、1日ぶんだけ手で書いた記録を入れておくと「どう溜まるか」が
伝わりやすい。ただし**買った人が最初に消せるよう、トグルの中に入れておく**。

### ⑤ 使い方のヒント（トグル）

- スマホのホーム画面に追加するとアプリのように使えます
- 音声ボタンで話すと、種類（運動・食事・睡眠・体調・メモ）まで自動で振り分けます
- 引っぱって更新すると最新になります

## 複製リンクの作り方

1. 作ったページの右上「共有」→「Webで公開」をオンにする
2. **「テンプレートとして複製を許可」**をオンにする
3. 表示されたURLの末尾に `?duplicate=true` を付けたものが複製リンク

```
https://〇〇.notion.site/xxxxxxxx?duplicate=true
```

このリンクをGumroadの商品に含める。

> 公開する前に、**自分の実際の記録が1件も残っていないこと**を必ず確認する。
> 体調・食事の記録は個人情報そのもの。サンプルは架空の内容で作り直すこと。

---

## 作る時の注意

- **凝りすぎない。** データベース化・ダッシュボード・数式を足すほど、アプリの
  書き込み形式と噛み合わなくなり、サポートの手間が増える
- テンプレートの中の文章は、Gumroadの商品ページとトーンをそろえる
- 日本語版と英語版を作るなら、**先に英語版を作る**。Notionテンプレートを買う層は
  英語圏のほうが圧倒的に厚い
